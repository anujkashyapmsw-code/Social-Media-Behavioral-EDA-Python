# Student Social Media Addiction & Academic Impact: Python EDA

An end-to-end exploratory data analysis (EDA) and statistical modeling project analyzing the relationship between digital screen time, academic outcomes, sleep patterns, and mental health metrics across 700+ student profiles using Python.

---

## 🔍 Key Analytical Insights
* **Screen Time Baseline:** Mean daily social media usage averages **4.92 hours/day**, with heavy-usage clusters exceeding 7 hours.
* **Academic Compromise:** Statistical segmentation shows over **64%** of respondents report measurable negative impacts on academic focus and performance.
* **Sleep Deprivation Pattern:** Strong negative correlation between daily platform usage and sleep duration, with high-addiction cohorts averaging under 6 hours of nightly rest.
* **Demographic Sensitivity:** High school student groups demonstrated higher sensitivity to addiction scores compared to postgraduate cohorts.

---

## 🛠️ Python Libraries & Analytical Methods
* **Data Processing & Transformation:** `Pandas`, `NumPy`
  * Missing value imputation, datatype normalization, column renaming, and feature engineering.
* **Exploratory Data Analysis (EDA):**
  * Univariate distributions (histograms, KDE curves) for usage hours and sleep metrics.
  * Bivariate and multivariate analysis examining addiction indices across academic tiers.
* **Statistical Visualization:** `Matplotlib`, `Seaborn`
  * Correlation heatmaps, categorical boxplots, violin distributions, and multi-variable pairplots identifying behavioral trends.
